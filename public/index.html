Capstone Project Architecture & 3-Student Distribution

This project proposes a unified, end-to-end framework integrating Dynamic/Static Application Security Testing (DAST/SAST), Transformer-based Deep Learning classification, False Positive reduction, and Contextual CVSS v3.1 Risk Prioritization. Each student owns and develops a distinct architectural module.

MODULE 1 STUDENT 1

Web Application Vulnerability Scanning

  • Automated crawler & attack surface mapper
  • HTTP Response security headers audit
  • OWASP Top 10 injection heuristics engine
  • Static Application Security Testing (SAST) for source code
Status: Fully Integrated & Verified
MODULE 2 STUDENT 2

AI-Based Analysis & Classification

  • Fine-tuned Transformer NLP vulnerability classifier
  • Automated CWE & OWASP taxonomy mapping
  • Contextual False Positive reduction pipeline
  • Interactive AI Security Copilot with attention heatmaps
Status: Fully Integrated & Verified
MODULE 3 STUDENT 3

Risk Prioritization & Reporting

  • CVSS v3.1 / v4.0 multi-factor calculation engine
  • Asset criticality multiplier & composite dynamic risk
  • Actionable SLA priority triage queue (P1 to P4)
  • Side-by-side code diffs & multi-format export (PDF, MD, JSON)
Status: Fully Integrated & Verified
